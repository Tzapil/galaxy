# Galaxy Sim

Браузерная детерминированная симуляция галактических цивилизаций. Игрок здесь —
наблюдатель: фракции самостоятельно строят экономику, исследуют технологии, проектируют
флоты, воюют, заключают договоры и переживают расколы.

## Быстрый старт

Требуются Node.js и Corepack.

```bash
corepack enable
corepack pnpm install
corepack pnpm build
corepack pnpm dev
```

Vite откроет клиент из `packages/client`. На стартовом экране доступны четыре пресета и
все параметры генерации; одинаковые seed и параметры дают одинаковую галактику.

## Интерфейс наблюдателя

- **Galaxy** — карта PixiJS с режимами владения, богатства, дефицита любого из 37
  ресурсов, трафика и регионального напряжения. Клик открывает систему.
- **System** — тела, врата, корабли, бой, здания с причинными состояниями, склады и
  теневые цены выбранного тела.
- **Events** — виртуализированная хроника войн, боёв, колоний, блокад, голода,
  исследований, кораблестроения, дипломатии, расколов и решений ИИ. Строка фокусирует
  систему, `Why?` раскрывает численную причину.
- **Data** — uPlot-графики цен, производства/потребления и мощи фракций на горизонте до
  10 000 лет, плюс сортируемое сравнение фракций.
- **Saves** — ручные слоты, три ротируемых автосейва, переименование, удаление и
  экспорт/импорт `.galaxy-save`. Существующий сейв можно открыть прямо со стартового
  экрана.
- **Settings** — скорость по умолчанию, автосейв, приборы и тема.

Симуляция работает в Web Worker. При перегрузке она замедляет игровое время, не
пропускает тики, а панель приборов показывает запрошенную и фактическую скорость.

## Пакеты

| Пакет                    | Назначение                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------- |
| `@galaxy-sim/sim-core`   | Чистое детерминированное ядро, SoA, очередь событий и бинарные снапшоты; без DOM.   |
| `@galaxy-sim/sim-data`   | 37 ресурсов и остальной JSON-контент, схемы, типы, валидатор и browser-safe bundle. |
| `@galaxy-sim/sim-worker` | Worker-протокол, срезы карты/системы, сюжетные батчи и агрегированная история.      |
| `@galaxy-sim/client`     | React, PixiJS и uPlot интерфейс наблюдателя; IndexedDB-сейвы.                       |
| `@galaxy-sim/tools`      | Headless-прогоны, golden-run, сценарии, стенды и валидаторы данных.                 |

## Проверки

Полный локальный набор:

```bash
corepack pnpm build
corepack pnpm test
corepack pnpm lint
corepack pnpm format:check
corepack pnpm validate:data
corepack pnpm golden:check
corepack pnpm scenarios:check
corepack pnpm stage8:acceptance
```

`stage8:acceptance` создаёт
`packages/tools/reports/stage-eight-acceptance.json`: измеряет целевую конфигурацию
500 систем / 20 000 кораблей / 50 000 зданий, полный сейв вместе с 10 000-летней
историей, render-срез и плавную деградацию.

Для обычных headless- и распределённых прогонов:

```bash
corepack pnpm sim:run -- --stage 7 --seed 20260904 --ticks 3650000
corepack pnpm bench -- --stage 7 --seeds 50 --years 10000
corepack pnpm stage7:long
```

Инструментовка не входит в хеш. `golden:check` должен оставаться неизменным после любых
правок UI и приборов; baseline обновляется только осознанно через `golden:update` с
причиной.

## Расширение контента

Перед изменением JSON прочитайте [руководство по расширению](docs/galaxy-sim-extending.md)
и [найденные ранее дефекты](docs/galaxy-sim-findings.md). Обязательный цикл после правки:
`validate:data` → тесты → `golden:check` → `scenarios:check`. Архитектурное ТЗ находится в
[galaxy-sim-spec.md](docs/galaxy-sim-spec.md), пошаговый план — в
[galaxy-sim-buildplan.md](docs/galaxy-sim-buildplan.md).
